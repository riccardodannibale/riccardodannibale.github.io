<h1>Complex Gym Website</h1>

<p class="project-subtitle">
A full-stack web application designed to manage a gym, with separate
functionalities for clients and employees.
</p>

</div>

<img
class="project-cover"
src="{{ '/assets/images/projects/gym/01.png' | relative_url }}"
alt="Complex Gym Website">

<div class="project-section">

<h2>Overview</h2>

<p>
The project consists of a complete web platform for gym management.
The application provides different interfaces and functionalities
depending on the user's role, with dedicated areas for clients and
employees.
</p>

<p>
The backend is implemented in PHP and the application uses a MySQL
database managed through XAMPP during development.
</p>

</div>


<div class="project-section">

<h2>What I developed</h2>

<ul>
<li>Client and employee authentication</li>
<li>User registration</li>
<li>Personal profiles</li>
<li>Calendar and booking management</li>
<li>Promotion management</li>
<li>Internal messaging</li>
<li>Member and entry management</li>
<li>Database connection and data management</li>
<li>Different interfaces according to the user role</li>
</ul>

</div>


<div class="project-section">

<h2>Architecture</h2>

<p>
The application is divided into multiple PHP modules according to
their responsibility. Dedicated pages handle authentication, profiles,
calendars, promotions, locations and messaging.
</p>

<p>
The database connection is centralized in <code>db.php</code>, while
the graphical presentation is organized into separate CSS files for
different pages and user roles.
</p>

</div>


<div class="project-section">

<h2>Technologies</h2>

<div class="project-stack">

<span class="stack-item">PHP</span>
<span class="stack-item">MySQL</span>
<span class="stack-item">HTML</span>
<span class="stack-item">CSS</span>
<span class="stack-item">Apache</span>
<span class="stack-item">XAMPP</span>
<span class="stack-item">ngrok</span>

</div>

</div>


<div class="project-section">

<h2>Development environment</h2>

<p>
The application can be executed locally using Apache and MySQL through
XAMPP. The project can also be exposed temporarily to the Internet
using ngrok for remote testing.
</p>

</div>
